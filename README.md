# El rastro de Elena Vega

Escape room para 4.º de ESO. Una periodista ha desaparecido mientras investigaba a la corporación OmniCorp. Los equipos siguen su rastro digital con un kit de herramientas: disco César, Morse, binario, mezclador RGB, localizador de IP y mapa.

Autor: Juan Luis Torralbo Muñoz.

## Publicarlo en GitHub Pages

1. Sube `index.html`, la carpeta `img/` y este `README.md` a la raíz del repositorio. Las imágenes antiguas (`gatoReto.jpg`, `puertos.png`, `mapa.jpg`, los recortes en `.png`…) ya no se usan y se pueden borrar.
2. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.

## En clase

- La partida se guarda sola: si alguien recarga la página, puede continuar. El reloj sigue corriendo.
- Al terminar aparece el tiempo oficial (tiempo real más penalizaciones) y un código de verificación para la clasificación.
